ONIX API Контакты

ONIX API 1.0

OAS 3.0. База: https://www.onixtg.shop. Авторизация: Authorization: Bearer <access> (JWT Ed25519) + cookie refresh __Host-onix_rt. Access в localStorage не кладётся.

Это API той же сессии, что и сайт (как кабинет STARVELL), не отдельный ключ мерчанта. Для ботов продавца используйте тот же вход (Telegram-бот / Google), затем вызывайте методы ниже. Ключи Т-Банка задаются только на сервере, клиенту не выдаются.

openapi: 3.0.3
info:
  title: ONIX API
  version: "1.0"
servers:
  - url: https://www.onixtg.shop

PROFILES

GET /api/users/me — профиль текущего пользователя (аналог STARVELL /api/profiles/me).

GET /api/users/{onixId} — публичный профиль.

CHATS

GET /api/chats — список чатов (аналог POST /api/chats/list).

GET /api/chats?q= — поиск.

POST /api/chats/direct — открыть диалог { "onixId" }.

Печатание — WebSocket /api/realtime, не отдельный HTTP send-typing.

MESSAGES

GET /api/chats/{id}/messages — история (аналог list-v2).

POST /api/chats/{id}/messages — отправить текст { "text" } (аналог /api/messages/send). Вложения в чате временно выключены.

OFFERS (лоты)

GET /api/products/mine — мои предложения.

GET /api/products/{id} и /api/products/lot/{n}.

POST /api/products — создать. PATCH /api/products/{id} — обновить.

ORDERS

GET /api/orders — список сделок.

GET /api/orders/{id} — сделка.

POST /api/orders/product/{productId} — купить (идемпотентность: заголовок/тело idempotencyKey).

POST /api/orders/{id}/deliver · /complete · /cancel · /dispute · /refund-request · /support.

REVIEWS

GET /api/users/{onixId}/reviews

POST /api/orders/{id}/reviews

PAYMENTS (Т-Банк sandbox)

GET /api/payments/methods — sbp/card true, когда на API заданы TINKOFF_TERMINAL_KEY и TINKOFF_PASSWORD.

POST /api/payments/intents — wallet: MAIN|DEPOSIT, provider: YOOKASSA (СБП) или CARD, amountCents, idempotencyKey. В ответе metadata: paymentUrl, qrPayload.

GET /api/payments/intents/{id} — статус до SUCCEEDED.

Нотификация банка: POST /api/payments/tinkoff/notification (публичный, без Bearer). В кабинете Т-Банка укажите этот URL.

SUPPORT

GET /api/support/tickets — мои тикеты.

POST /api/support/appeals — апелляция.
