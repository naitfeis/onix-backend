ONIX API Контакты

ONIX API

База: https://www.onixtg.shop. Нужна та же сессия, что и на сайте.

Чаты

GET /api/chats — список. Поиск: ?q=.

POST /api/chats/direct — открыть диалог { "onixId" }.

GET /api/chats/{id}/messages — история.

POST /api/chats/{id}/messages — текст { "text" }.

Лоты

GET /api/products/mine — мои предложения.

GET /api/products/{id} и /api/products/lot/{n}.

POST /api/products — создать. PATCH /api/products/{id} — обновить.
