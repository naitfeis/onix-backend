# Урок 1 — программа, переменные и типы

## Цель
Понять, как компьютер выполняет инструкции сверху вниз, и самостоятельно написать маленькую программу без Cursor.

## Объяснение
`console.log()` выводит результат. `const` создаёт переменную, которую нельзя переназначить; `let` можно переназначить. Типы: `string` — текст, `number` — число, `boolean` — true/false. `=` присваивает, `===` сравнивает.

```js
const price = 700;
let balance = 5000;
balance = balance - price;
console.log(`Остаток: ${balance} ₽`);
```

## Практика
Измени цену, баланс и количество. Объясни каждую строку вслух. Проверь `10 + 5` и `"10" + "5"`.

Напиши программу с `name`, `balance`, `price`, `quantity`, которая считает общую цену и остаток. Не копируй готовый код. Отправь код и ответы: что такое переменная, тип и разница `=`/`===`.
