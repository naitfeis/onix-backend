# Урок 8 — some и every

## Цель
Проверять наличие хотя бы одного элемента и корректность всех элементов.

`some` отвечает «есть ли хотя бы один?»; `every` — «все ли?». Оба возвращают boolean.

```js
const hasRoblox = buyers.some((b) => b.type === 'Roblox');
const valid = buyers.every((b) => b.price > 0 && b.quantity > 0);
```

Пустой массив: `some` false, `every` true; для корзины отдельно проверяй `length`.

## Самостоятельно
Проверь наличие Roblox, отрицательного баланса, положительность всех цен и целостность количества. Подписи вывода должны соответствовать смыслу true/false.
