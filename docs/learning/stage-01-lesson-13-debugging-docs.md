# Этап 1. Урок 13 — отладка и чтение документации

## Цель

Не угадывать исправление, а находить первую причину ошибки по фактам.

## 1. Основные виды ошибок

`SyntaxError` — код невозможно разобрать: лишняя скобка, незакрытая кавычка, неправильное `else`.

`ReferenceError` — имя не существует в текущем scope: `console.log(quantity)` вне функции, если quantity был параметром.

`TypeError` — значение существует, но операция для него невозможна: `foundBuyer.name`, если `foundBuyer` равен `undefined`.

Логическая ошибка — программа запускается, но делает неправильный расчёт: списание произошло до проверки баланса.

## 2. Алгоритм отладки

1. Прочитать сообщение ошибки полностью.
2. Найти тип ошибки.
3. Перейти к строке и нескольким строкам выше.
4. Найти первое значение, которое стало неправильным.
5. Добавить временный `console.log` входа и промежуточного результата.
6. Исправить причину, а не только последнюю строку.
7. Повторить позитивный и негативный тест.

Пример:

```js
const found = buyers.find((buyer) => buyer.name === "Anna");
console.log(found.name);
```

Гипотеза: `found` равен `undefined`. Проверка:

```js
console.log({ found });
```

Исправление:

```js
if (found) {
  console.log(found.name);
} else {
  console.log("Покупатель не найден");
}
```

## 3. Область видимости

Если переменная объявлена внутри `{}` или функции, снаружи её нет:

```js
if (true) {
  const message = "ok";
}

// console.log(message); // ReferenceError
```

Проверяй, где переменная объявлена и где используется.

## 4. Точки останова

В Node.js можно временно использовать `console.log({ balance, price, quantity })`. В браузерных DevTools ставь breakpoint и проверяй Scope, Call Stack и значения по шагам. Удаляй диагностические логи после исправления.

## 5. Чтение документации

Для любого метода изучай:

- что принимает;
- что возвращает;
- изменяет ли исходные данные;
- что происходит с пустым массивом;
- какие ошибки возможны;
- минимальный пример.

Для `find`, например: возвращает элемент или `undefined`; останавливается на первом совпадении; исходный массив не меняет.

## Самостоятельное задание

Создай файл с 6 намеренно сломанными короткими примерами: SyntaxError, ReferenceError, TypeError, неверный `return`, неправильная область видимости и логическая ошибка оплаты. Исправляй по одному. Для каждого запиши: сообщение, причина, исправление, тест.
