# Урок 18 — TypeScript

## Цель
Сделать контракты данных явными.

Изучи `type`/`interface`, union, optional properties, `unknown`, narrowing, generics, `Partial`, `Pick`, `Omit`, `Record`, DTO.

## Самостоятельно
Опиши типы Buyer и Product, напиши безопасную функцию расчёта и type guard для неизвестного API-ответа. Не используй `any`.
