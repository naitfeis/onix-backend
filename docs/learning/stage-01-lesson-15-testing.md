# Этап 1. Урок 15 — ручное тестирование и итоговый проект

## Цель

Научиться доказывать, что программа работает не только на удачном примере.

## 1. Тест — это сценарий

Для каждого сценария фиксируй вход, ожидаемый результат и фактический результат:

```text
Название: нехватка баланса
Вход: balance=1000, price=700, quantity=2
Ожидается: ok=false, balance=1000
Факт: ...
```

## 2. Позитивные и негативные случаи

Позитивные: обычная цена, целое количество, успешная оплата, покупка на весь баланс.

Негативные: цена 0, отрицательная цена, `NaN`, `Infinity`, quantity 0, -1, 2.5, отсутствующий товар, нехватка денег.

## 3. Инварианты денежных операций

После отказа:

```text
balanceAfter === balanceBefore
stockAfter === stockBefore
```

После успеха:

```text
balanceAfter === balanceBefore - finalPrice
stockAfter === stockBefore - quantity
```

Нельзя принять отрицательное количество: иначе вычитание отрицательного числа увеличит склад или баланс.

## 4. Простой assert

Пока можно использовать собственную проверку:

```js
function assertEqual(actual, expected, title) {
  if (actual !== expected) {
    throw new Error(`${title}: ожидалось ${expected}, получено ${actual}`);
  }
  console.log(`PASS: ${title}`);
}
```

Пример:

```js
assertEqual(2 + 2, 4, "сложение");
```

## Самостоятельное задание

Сделай минимум 10 проверок для своей покупки: успех без скидки, успех со скидкой, точный баланс, нехватка на 1 ₽, цена 0, отрицательная цена, `NaN`, `Infinity`, количество 0, -1 и 2.5. При каждом отказе проверь, что исходный баланс не изменился.

## Урок закрыт, если

Твои тесты ловят намеренно сломанное условие и ты можешь объяснить, какой инвариант нарушился.
