# Урок 13 — модули и документация

## Цель
Разделять код по ответственности.

`export` делает функцию доступной из файла, `import` подключает её. Вынеси расчёт цены, валидацию и вывод в отдельные файлы. Читай документацию по параметрам, возвращаемому значению и исключениям.

## Самостоятельно
Создай `price.js`, `validation.js`, `main.js`; экспортируй `calculatePrice` и `validateQuantity`; импортируй их и проведи 3 теста.
