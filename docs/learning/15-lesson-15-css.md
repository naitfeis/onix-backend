# Урок 15 — CSS

## Цель
Научиться оформлять и адаптировать HTML.

Изучи селекторы, каскад, box model, Flexbox, Grid, `position`, CSS variables, media queries, `hover`, `focus`, `disabled`.

## Самостоятельно
Оформи каталог ONIX: сетка карточек, баланс, зелёный успех, красная ошибка, мобильная ширина. Проверь keyboard focus и экран до 600px.
