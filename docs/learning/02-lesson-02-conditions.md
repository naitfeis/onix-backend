# Урок 2 — операторы и условия

## Цель
Научиться принимать решения и не списывать деньги при ошибке.

```js
if (balance >= totalPrice) {
  balance = balance - totalPrice;
  console.log('Успех');
} else {
  console.log('Недостаточно средств');
}
```

`>`, `<`, `>=`, `<=`, `===`, `!==` сравнивают. `&&` означает И, `||` — ИЛИ, `!` — НЕ. Фигурные скобки определяют ветку.

## Самостоятельно
Добавь скидку при `quantity >= 5` и комиссию иначе. Проверь баланс 5000, 2100 и 1000. Важно: проверка должна быть до списания.
