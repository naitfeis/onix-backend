# Урок 19 — React

## Цель
Понять UI ONIX: component → state → event → API → loading → success/error.

Изучи JSX, props, state, hooks, forms, lists, keys, routing, API calls и состояния интерфейса.

## Самостоятельно
Собери каталог: карточки товаров, поиск, форма покупки, баланс, loading/error/success. Не смешивай расчёт с отображением.
