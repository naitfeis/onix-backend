# Урок 14 — HTML

## Цель
Понять структуру страницы и семантический DOM.

Изучи `html`, `head`, `body`, `header`, `main`, `section`, `article`, `button`, формы, `label`, `input`. Семантика помогает доступности и поисковым системам.

## Самостоятельно
Создай страницу без React: заголовок ONIX, карточки трёх товаров, поля имени/количества и кнопку «Купить». Используй правильные labels и кнопки.
