# Урок 9 — reduce

## Цель
Собрать массив в одно значение.

```js
const total = buyers.reduce((sum, buyer) => {
  return sum + buyer.balance;
}, 0);
```

`sum` — накопитель, второй параметр `0` — начальное значение. Для пустого массива это безопасно.

## Самостоятельно
Посчитай общий баланс, общую базовую стоимость, общее количество и сумму только Roblox через `filter().reduce()`.
