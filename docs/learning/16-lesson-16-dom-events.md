# Урок 16 — DOM, события и формы

## Цель
Связать HTML с JavaScript.

Изучи `querySelector`, `textContent`, `classList`, `addEventListener`, `preventDefault`, `value`. Событие — сообщение браузера о действии пользователя.

## Самостоятельно
При отправке формы прочитай цену и количество, преобразуй их через Number, вызови расчёт покупки, покажи результат в DOM и обработай ошибку.
