# Урок 3 — функции

## Цель
Убрать повторение и возвращать результат, а не только печатать его.

```js
function total(price, quantity) {
  return price * quantity;
}
const result = total(700, 3);
```

Параметр — имя внутри объявления, аргумент — переданное значение. `return` передаёт значение наружу и сразу останавливает функцию. Переменные внутри функции локальные.

## Самостоятельно
Создай `calculatePurchase(quantity, price)`: при `quantity <= 0` вернуть 0, от 5 дать скидку 10%, иначе комиссию 10%. Проверь 0, 3 и 5.
