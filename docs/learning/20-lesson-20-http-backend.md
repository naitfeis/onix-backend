# Урок 20 — HTTP и NestJS

## Цель
Понять путь Browser → API → database.

Изучи GET/POST/PATCH/DELETE, status codes, headers, cookies, Authorization, CORS; затем Nest modules, controllers, services, DI, DTO, pipes, guards, middleware, transactions.

## Самостоятельно
Опиши endpoint создания заказа и раздели controller, service и repository. Для каждого укажи ответственность.
