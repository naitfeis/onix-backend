# Урок 5 — массивы и циклы

## Цель
Обрабатывать много пользователей и товаров.

Массив использует `[]`, индексы начинаются с 0, `.length` показывает количество элементов, `push()` добавляет элемент. `for...of` проходит по каждому элементу.

## Самостоятельно
Создай массив из 3 товаров `{name, price, quantity}`, добавь четвёртый через `push()`, выведи все товары циклом и посчитай общую стоимость склада через накопитель `let total = 0`.
