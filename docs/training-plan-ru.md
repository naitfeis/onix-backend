# ONIX: учебный план программирования с нуля

Рабочий план. Код проекта не изменяется. После каждого задания ученик отправляет свой код; затем разбираем ошибки, крайние случаи и даём следующую самостоятельную практику.

## Режим

5–6 часов в день, 6 дней в неделю; 1 день — отдых и лёгкое повторение.

- 60–90 минут: теория.
- 2–3 часа: самостоятельный код без копирования.
- 60–90 минут: мини-проект или связь с ONIX.
- 30–45 минут: отладка, чтение ошибок, конспект.

Интенсивный режим не означает работу без перерывов: дели занятия на блоки и сохраняй время на сон.

## План ближайшей недели

### День 1 — ошибки JavaScript
- `undefined`, `null`, `NaN`.
- `throw`, `try/catch/finally`.
- Безопасная функция `buy`.
- Практика: успешная покупка, нехватка денег, плохая цена, плохое количество, `NaN`.

### День 2 — деструктуризация и spread
- Объектная и массивная деструктуризация.
- Переименование свойств.
- Spread для копии объекта и массива.
- `map()` + spread для обновления Saveliy в новом массиве.

### День 3 — закрепление методов массивов
- `find`, `filter`, `map`, `some`, `every`, `reduce`.
- Практика на заказах `PAID`, `PENDING`, `CANCELLED`.
- Задание: оплаченные заказы, имена покупателей, итоговая сумма.

### День 4 — модули и документация
- `import` / `export`.
- Разделение расчётов, валидации и вывода по файлам.
- MDN: параметры, возвращаемое значение, ошибки, примеры.
- Базовая отладка в Node.js и DevTools.

### День 5 — HTML
- Структура документа и семантические теги.
- Заголовки, ссылки, изображения, формы.
- `label`, `input`, `button`, доступность.
- Практика: карточка товара ONIX без React.

### День 6 — CSS
- Селекторы, каскад, box model.
- Flexbox, Grid, размеры, отступы.
- CSS variables, `hover`, `focus`, `disabled`.
- Responsive design.

### День 7 — контрольный мини-проект
- Мини-магазин без React: каталог, карточки, баланс, кнопка покупки.
- Проверка крайних значений и исправление ошибок.
- Объяснение своего кода своими словами.

## Следующие этапы

### Недели 2–3: браузерный JavaScript
DOM, события, формы, валидация, `localStorage`, `fetch`, JSON, Promise, `async/await`, состояния loading/success/error.

### Недели 4–5: TypeScript
`type`, `interface`, union, narrowing, `unknown`/`any`, optional properties, generics, `Partial`, `Pick`, `Omit`, `Record`, DTO и API-контракты.

### Недели 6–8: React
JSX, компоненты, props, state, hooks, формы, списки, routing, API-запросы и состояния интерфейса.

### Недели 9–12: HTTP и backend
HTTP, REST, headers, cookies, CORS, статус-коды, Node API, NestJS modules/controllers/services/DI, DTO, pipes, guards, middleware, interceptors.

### Недели 13–16: PostgreSQL и Prisma
Таблицы, primary/foreign keys, indexes, JOIN, constraints, transactions, Prisma schema, relations, migrations, queries.

### После 16 недель: безопасность и production
Сессии, cookies, JWT, refresh tokens, XSS, CSRF, rate limiting, MFA, device trust, audit logs, Ed25519/EdDSA, Git, тесты, Docker, Vercel, Render, Neon, логи и мониторинг.

При 5–6 качественных часах в день базовое понимание можно получить примерно за 3–4 месяца, чтение большей части ONIX — за 6–10 месяцев. Production-уровень требует длительной практики.

## Правило каждого урока

1. Объяснение простой идеи.
2. Пример на твоём `buyer`/`buy`.
3. Самостоятельное задание без готового решения.
4. Ты отправляешь код.
5. Разбираем результат и ошибки.
6. Проверяем крайние случаи.
7. Переходим дальше только после понимания.

## Следующее задание

Тема: `try/catch`, `throw` и безопасная обработка ошибок на функции `buy`.

Нужно будет выбрасывать ошибку для некорректной цены или количества, ловить её через `try/catch` и доказывать, что баланс не изменился.
